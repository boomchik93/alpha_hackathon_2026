# product

Продукт и аналитика: что строим, для кого, как поймём, что получилось.

Сервис называется «Альфа Сигнал» (персональная лента событий для руководителей). Работающий стенд: https://semenovm.ru/alpha26/login. Продуктовая часть: Пономарева Софья.

| Документ | Что внутри |
|---|---|
| [ROLE_PRODUCT.md](ROLE_PRODUCT.md) | требования кейса: критерии 01–12, ограничения 01–06, формат сдачи |
| [vision.md](vision.md) | проблема, ценность, роли пользователей и решения после карточки, путь пользователя |
| [requirements.md](requirements.md) | границы MVP, нефункциональные требования, критерии готовности со статусом |
| [metrics.md](metrics.md) | метрики контента, персонализации и AI-слоя, пороги, действия, регламент мониторинга |
| [demo/scenario.md](demo/scenario.md) | сценарий демо, демо-компании, подготовка, запасной план |
| [user_story.md](user_story.md) | боли и ожидания пользователя, путь по этапам, пример кейса |

Обратная связь из интерфейса сохраняется в бэкенде и ML-слое (`POST /api/cards/{id}/feedback`, сводка `GET /api/feedback/summary`) и видна на экране «Мониторинг».
