# Требования и границы MVP

Редакция от 2026-10-26, Пономарева Софья (первый черновик от 2026-10-25). Нумерация критериев (01–12) и ограничений (О01–О06) как в PDF кейса и [ROLE_PRODUCT.md](ROLE_PRODUCT.md).

## Входит в MVP (показываем на демо)

| Блок | Что есть | Где в коде |
|---|---|---|
| Профиль компании | 115 компаний и группы выше 15 млрд; отрасль, масштаб, продукты банка, ВЭД, контрагенты из платежей, положение в отрасли | `ml/profile`, `GET /companies/{id}` |
| Сбор новостей | сборщик по расписанию + аналитика банка (9 PDF, распознаны Qwen3-VL) | `backend/news_collector`, `ml/live.py`, `ml/ingest` |
| Лента | отбор и ранжирование под компанию, причины, основная лента и «Может быть интересно», счётчик отсеянного | `ml/ranking`, `GET /companies/{id}/feed` |
| Карточка | шесть блоков кейса, роль меняет акцент, `bank_view` из дословных цитат, `ai_inference` отдельно | `ml/agent`, `GET .../insights/{item_id}` |
| Агентная логика | план, инструменты только на чтение, повтор поиска, верификатор, сверка противоречий (флаг) | `ml/agent`, трасса `GET /traces/{id}` |
| Взаимодействие | уточняющий вопрос, сценарии, переход к странице PDF, история | `POST /cards/{id}/followup`, `/scenarios`, `/sources/{doc_id}/pdf` |
| Обратная связь и мониторинг | «полезно / не полезно» с причиной, оценки экспертов отдельно, экран мониторинга, журнал обращений | `POST /cards/{id}/feedback`, `MonitoringPage.tsx`, `/admin/audit` |
| Доступ | вход по логину, роли пользователей, доступ только к своим компаниям, эксперт и администратор | `backend/app/auth.py`, `backend/seed_users.json` |
| Бюджет | общий журнал расхода, остановка платных вызовов на 90% лимита 500 руб. | `ml/llm`, `var/spend.jsonl` |
| Интерфейс | точка входа на главном экране, лента, карточка, трасса, мониторинг | `frontend/` |

## Не входит в MVP

- Реальная интеграция с интернет-банком Альфа-Бизнес: интерфейс повторяет его по духу, вход по тестовым учётным записям.
- Компании ниже порога 15 млрд и весь датасет 85 тыс. компаний: подход описан в слайде о масштабировании.
- Push-уведомления, e-mail-дайджест.
- Мобильная версия как отдельный продукт.
- Автоматические действия от имени клиента: сервис только информирует и предлагает направления.

## Нефункциональные требования

| Требование | Цель | Сейчас |
|---|---|---|
| Время открытия карточки | предрасчитанная < 1 с; новая p95 ≤ 35 с с индикатором прогресса | p50 / p95 ~15 / 31 с, предрасчёт есть |
| Расход | демо-день ≤ 100 руб.; общий лимит 500 руб./день | карточка ~0,15–0,3 руб. |
| Только разрешённые LLM | список Приложения 3; e5 локально с письменного разрешения | e5 разрешён устно |
| Безопасность (О06) | права по компаниям, инструменты только на чтение, журнал, вырезание инструкций из текстов | реализовано, нужен слайд |
| Неполные данные (О05) | пометки об ограничениях в карточке | есть, показать на «трудной» компании |
| Воспроизводимость | `docker compose up --build` из чистого клона | **нет**: нужны `data/` и `var/` |

## Критерии готовности (Definition of Done для сдачи)

| № | Критерий | Готово, когда | Статус |
|---|---|---|---|
| 01 | Контекст и отбор | у трёх демо-компаний разные ленты; у каждого материала причина; виден счётчик отсеянного; AUC «кому показать» на свежем наборе real2 посчитан | ленты есть, real2 после 26.10 |
| 02 | Содержательная интерпретация | на эталонном примере кейса (ставка 14%, кредит у клиента) карточка говорит про стоимость долга, а не пересказывает решение ЦБ; 15–20 карточек вычитаны продуктом | вычитка не проведена, чек-лист готов |
| 03 | Банк vs модель | в каждой релевантной карточке `bank_view` из цитат с документом и страницей или явная пометка «аналитики нет» | `bank_view` у 82% релевантных; пустые в основном там, где аналитики банка по теме нет |
| 04 | Источники и факты | у каждого риска и действия `evidence`; цифры проверены кодом; доля неподтверждённого не выше прошлой версии в одном сеансе судьи | есть, ручной калибровки нет |
| 05 | Новые новости | одна новость, которой не было в наборе, проходит путь до карточки на демо; итог на real2 | после 26.10 |
| 06 | Сквозной сценарий | [demo/scenario.md](demo/scenario.md) отрепетирован целиком на живых моделях, с замером времени | не отрепетирован |
| 07 | Мониторинг | [metrics.md](metrics.md) с регламентом; экран мониторинга с оценками команды | экран есть, оценок мало |
| 08 | Взаимодействие | уточняющий вопрос, другой разрез (роль, компания/группа), переход к странице PDF | есть |
| 09 | Агентность | трасса с планом и хотя бы одним повтором или сверкой противоречий | повтор ~3% карточек, сверка выключена |
| 10 | Трассируемость | экран «Как получен вывод» открывается из карточки | есть |
| О06 | Безопасность AI | раздел README и слайд с местом в архитектуре | раздел в `ml/OVERVIEW.md` |
| Сдача | формат | тег и hash в README, доступ `alfa-hack-2026`, `THIRD_PARTY_NOTICES.md`, lock-файлы, OpenAPI | OpenAPI и notices есть, тега нет |
