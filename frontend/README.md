# frontend — «Альфа Сигнал»

Интерфейс персональной новостной аналитики внутри интернет-банка Альфа-Бизнес. Показывает не пересказ новостей, а влияние события на конкретную компанию и роль руководителя. План работ — `plan.md`.

## Запуск

Нужен Node.js 20 или новее.

```bash
cd frontend
npm install
npm run dev          # http://localhost:5173, работает на моках, бэкенд не нужен
```

С настоящим бэкендом (он на `:8000`, см. корневой README):

```bash
VITE_USE_MOCK=0 npm run dev                       # /api проксируется на http://localhost:8000
VITE_USE_MOCK=0 VITE_API_PROXY=http://host:8000 npm run dev
```

Весь стек одной командой из корня репозитория: `docker compose up --build`, фронт откроется на http://localhost:8080. Сервис `frontend` в `docker-compose.yml` собирает образ из этой папки: nginx отдаёт статику и проксирует `/api/` на `backend:8000` без изменения пути. В образе фронт всегда работает с бэкендом (`VITE_USE_MOCK=0`).

| Команда | Что делает |
|---|---|
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run build:demo` | всё в один файл `dist-demo/index.html` на моках: открывается без сервера, можно выложить на Netlify |
| `npx tsc -b` | проверка типов |

## Стек

React 19, TypeScript, Vite, React Router, TanStack Query (запросы, кэш, опрос фоновых задач), Lucide Icons, шрифт Manrope из `@fontsource` (без внешних CDN), обычный CSS с токенами, светлая и тёмная тема. Версии пакетов закреплены.

## Контракт

Типы в `src/api/types.ts` повторяют `ml/schemas.py`, клиент `src/api/http.ts` — ручки из `backend/app/routes.py`. Меняются только вместе с ними.

| Экран | Ручки |
|---|---|
| Вход, восстановление сессии | `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/me` (токен в `Authorization: Bearer`) |
| Шапка, главная | `GET /api/companies`, `GET /api/me/summary`, `GET /api/companies/{id}/feed` |
| Лента | `GET /api/companies/{id}/feed` с фильтрами `tier`, `source_kind`, `topic`, `date_from`, `hide_stale` |
| Профиль | `GET /api/companies/{id}` |
| Карточка | `GET /api/companies/{id}/insights/{item_id}`: 200 — готовая карточка, 202 — задача, опрос `GET /api/jobs/{job_id}` раз в секунду |
| Сценарии | `GET …/insights/{item_id}/scenarios` по кнопке: 200, 202 с опросом или 422 `scenarios_not_applicable` |
| Вопрос, оценка | `POST /api/cards/{id}/followup`, `POST /api/cards/{id}/feedback` |
| Трасса, первоисточник | `GET /api/cards/{id}/trace`, `GET /api/sources/{doc_id}/pdf` (скачивается с токеном, открывается blob-ссылкой с `#page=N`) |
| Мониторинг | `GET /api/health`, `GET /api/feedback/summary` (эксперт, админ), `GET /api/admin/audit` (админ) |

Роль: обычному пользователю её задаёт профиль, эксперт и админ выбирают «Смотреть как», и фронт передаёт `?role=`. Ошибки показываются по `code` из ответа (`src/dict/labels.ts`, `ERROR_TEXT`), у 5xx есть «Повторить».

История вопросов хранится в браузере (отдельно для каждого логина): ручки истории в бэкенде нет.

## Что реализовано

| Экран | Путь | Критерии кейса |
|---|---|---|
| Вход с тестовыми аккаунтами | `/login` | учётные записи из `backend/seed_users.json` |
| Главная интернет-банка | `/` | главный блок и пункт меню со счётчиком новых событий (К09) |
| Лента | `/feed` | персональная лента, «Может быть интересно», счётчик отсеянного, фильтры, разрез «вся группа / компания-участник» (К05, К10) |
| Карточка влияния | `/insight/:id` | что произошло, «почему вам» с признаками профиля, риски и возможности с источником или пометкой «вывод модели», действия, позиция банка дословно и отдельно от вывода модели (К03, О02), ограничения (О05), вопрос, оценка с причиной (К08) |
| Сценарии | в карточке | развилка, хороший / базовый / плохой исход, матрица «решение × исход», рекомендация и сигналы |
| Генерация | в карточке | индикатор по статусу фоновой задачи, можно уйти и вернуться |
| Первоисточник | `/source/:itemId/:sourceId` | PDF аналитики на нужной странице или ссылка на новость (К10) |
| Трасса | `/trace/:itemId` | план, вызовы инструментов, проверки, повторы, источники, признаки профиля; стоимость видят эксперт и админ (К11, К12) |
| Профиль компании / группы | `/profile` | признаки с путями полей, продукты банка, состав группы, пробелы в данных (О05) |
| История вопросов | `/history` | вопросы с переходом к карточке |
| Мониторинг | `/monitoring` | ML, расход против бюджета 500 ₽ (О04), оценки пользователей и экспертов отдельно, по ролям, причины, версии промпта; журнал — только админ (К08) |
| Счета, задачи | `/finances`, `/tasks` | антураж интернет-банка |

## Мок

`src/api/mock.ts` и `src/api/fixtures.ts` ведут себя как бэкенд: те же ответы, коды ошибок и задачи 202 → опрос. Компании и пользователи — из seed и выборки ML, новости — из `ml/fixtures/news.jsonl`, тексты карточек и сценариев написаны для демо. В моке:

- карточка генерируется около 6 секунд, сценарии около 9;
- карточка «Золото обновило рекорд…» с первого раза падает с `model_failed` — видно «Повторить»;
- сценарии есть для ставки ЦБ, бензина, стального проката и обзора банка, для остальных — 422 «сценарии не строятся»;
- PDF аналитики нет, на экране первоисточника показан фрагмент с цитатой.

## Что показать на демо

1. `retail.cfo` → главная → «Разобрать главное» (ставка ЦБ): генерация, источники по клику, позиция банка отдельно от вывода модели.
2. «Построить сценарии»: развилка, три исхода, какие решения помогают в каждом.
3. Вопрос «Что ожидает банк?», затем трасса и первоисточник.
4. `build.accountant` — профиль с пропусками, ограничения в карточке. `group.cfo` — разрез по компаниям группы.
5. `expert` — «Смотреть как» меняет акцент карточки, оценка учитывается отдельно. `admin` — мониторинг и журнал.

## Структура

```
src/
  api/          типы контракта, http-клиент, мок и демо-данные, хуки запросов
  auth/         сессия: пользователь, компания, роль
  components/   оболочка (меню, шапка, уведомления, тема) и общие элементы
  dict/         русские подписи, коды ошибок, темы, поля профиля, даты
  lib/          история вопросов в браузере
  pages/        экраны; insight/ — карточка, сценарии, вопросы, источник, трасса
  styles.css        базовый визуал «Альфа Сигнал»
  styles-extra.css  стили новых блоков, обе темы
```
